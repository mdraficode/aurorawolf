## 1 · What actually happened

The prior session (`arena/01a07938-aurorawolf`, merged as PR #8 / commit `56cb727`) recovered
`src/p1.js`–`p6.js` from the embedded v6.9 `index.html` after a Drive-patch reconciliation, and
concluded that the game could not be launched in this sandbox because "SwiftShader shader
compilation stalls indefinitely" — a supposed environment limitation, confirmed (their words) by a
600-second timeout where `state` never left `undefined` and `CAMP`/`RUN` never initialized. That
session then self-issued a trainer verdict (`--verdict=promote`) and stopped, unable to run a single
real Tiger Legend attempt.

**That diagnosis was wrong.** The game was never reaching a shader stall — it was crashing before the
first line of the bundle's own game code finished parsing, because of two real, on-disk defects
introduced during that source recovery:

1. **`src/p1.js` was missing its opening `/*`.** Every `src/pN.js` file in this codebase is written to
   be concatenated back-to-back by `build.py` (`p1 + p2 + p3 + p4 + p5 + p6 + autopilot`, joined by
   `\n`), and each file after the first *deliberately* opens with plain header text and a bare `*/` —
   the **previous** file supplies the matching `/*` at its own tail. `p1.js` is first in the chain, so
   it must carry its own opening `/*`; the recovered file didn't, so the very first characters of the
   whole bundle (`   Part 1 — math, noise, terrain & biome functions`) were fed to the JS parser as
   code, not a comment → `SyntaxError: Unexpected number` → the entire inline `<script>` (which holds
   the whole game) never executed at all. Nothing initialized: no `THREE` usage past parse, no `CAMP`,
   no `state`, no `btnStart`. A headless page that never runs its own script looks exactly like a page
   stuck compiling shaders if you only check `waitForFunction(() => state === 'play')` — that was the
   false signal the previous two sessions chased for hours.
2. **`src/p6.js` had a duplicated, truncated tail.** Someone had appended a partial, corrupted second
   copy of `autopilot.js`'s opening comment block plus its first two lines (`(function () { const
   URL_ON = ...`) onto the *end* of `p6.js`, after `p6.js`'s own `window.PACK = (() => {...})();` was
   already fully closed. Since `autopilot.js` (the very next file concatenated) already begins with
   that exact comment and `(function () {` opener in full, this stray fragment left a dangling,
   unclosed `(function () {` in the bundle with no matching `})()` — `SyntaxError: Unexpected end of
   input` at the very end of the 11,791-line bundle.
3. **`src/p2.js` had regressed rendering/fog settings**, with the correct version preserved
   side-by-side as `src/p2.js.bak` (added in the same recovery commit but never used or reconciled):
   `scene.fog = null` instead of `new THREE.Fog(...)`, shadows/AA/tone-mapping disabled unconditionally
   instead of gated on `QUALITY`. `src/p4.js`'s weather loop (`scene.fog.color.copy(...)`,
   `scene.fog.far += ...`) and four different test suites (`events`, `hunt`, `mystic`, `world`)
   unconditionally dereference `scene.fog.color` / `scene.fog.far` — with `p2.js`'s `null`, every one
   of those would throw `Cannot read properties of null (reading 'color')` the first time the day/night
   loop ticked. This was masked earlier only because the syntax errors above killed the script before
   reaching that line.

**Fixed, in order, and verified after each step:**
- `src/p1.js`: added the missing `/* ================...` opener.
- `src/p6.js`: deleted the stray duplicated/truncated tail (18 lines, everything after the real
  `})();` that closes `window.PACK`).
- `src/p2.js`: restored from `src/p2.js.bak` (the correct version — antialias on, shadows/AA/tone-map
  gated on `QUALITY`, `scene.fog = new THREE.Fog(0x87b7d9, 70, 165)`); `src/p2.js.bak` deleted (its job
  is done, and it's not a real workspace convention — nothing else in the repo uses `.bak` files).
- `python3 build.py` after each change; `node --check` on the extracted inline `<script>` bundle
  confirmed valid JS syntax only after all three fixes landed together.
