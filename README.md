# 🐺 REVONTULET · Aurora Wolf

A 3D open-world wolf simulator in a **single self-contained HTML file** — no installs, no internet-dependent assets, runs straight in the browser.

**▶ Play:** https://mdraficode.github.io/aurorawolf/

## Features
- Infinite procedural terrain — 6 blending biomes, day/night cycle, weather, auroras
- Realistic aggressive wolf: sprint, jump, swim, howl, wolf-sense
- ⚔️ Hunt with bite & claw — prey in 3 difficulty tiers (rabbit → elk), rewards: meat, pelts, bones
- ✨ Rare magic mushrooms grant 10 seconds of flight
- Touch controls + landscape layout for phones, keyboard for desktop
- Every world unique — add `?seed=1234` to the URL

## Tech
Three.js (embedded), procedural simplex-noise terrain, instanced vegetation, WebAudio. One file: `index.html`.

## Update
This repo **is** the live game — pushing a new `index.html` updates the site within about a minute.
